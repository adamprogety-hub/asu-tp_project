# Изображения для этапов работы (Process Slides)

Загрузите сюда изображения для 6 этапов работы.

Рекомендуемый формат: `.png` или `.webp` или `.jpg`.
Рекомендуется использовать горизонтальные или фоновые изображения для карточек этапов.

Рекомендуемые названия для замены:
1. `step-01.png` — Обследование
2. `step-02.png` — Проектирование
3. `step-03.png` — Программирование
4. `step-04.png` — Монтаж / сборка
5. `step-05.png` — Пусконаладка
6. `step-06.png` — Сопровождение
