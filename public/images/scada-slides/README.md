# Реальные мнемосхемы (SCADA Mimic Diagrams)

Загрузите сюда ваши изображения мнемосхем для слайдера. 

Рекомендуемый формат: `.png` или `.webp`.
Рекомендуемое разрешение: `1200x535` или аналогичное горизонтальное соотношение сторон.

Примерные названия для замены:
1. `slide-01.png` — Обзор объекта
2. `slide-02.png` — Приточная установка
3. `slide-03.png` — Климатические зоны
4. `slide-04.png` — Энергопотребление
5. `slide-05.png` — Аварии и события
6. `slide-06.png` — Тепловой контур
7. `slide-07.png` — Сеть объектов
